# Disclaimer

This repository is for **defensive security education**. The attack-simulation steps exist only to generate realistic telemetry so that detections can be built and tested.

- Run them **only** in an isolated lab environment that you own, or where you have explicit written permission to test.
- Never point any of the commands at systems, networks, or accounts you are not authorized to test. Unauthorized access is illegal in most jurisdictions.
- The commands are standard, publicly documented usage of common security tools (Nmap, Hydra, Metasploit modules for intentionally vulnerable VMs, Netcat, Sysinternals). The repository contains no malware, exploit code, or weaponized payloads.
- Intentionally vulnerable targets (DVWA, Metasploitable) must stay on host-only or internal networks.
- All sample data is synthetic and uses RFC 5737 documentation IP ranges and placeholder hostnames.
